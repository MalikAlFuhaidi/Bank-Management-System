# 🏦 Bank Management System (C++)

A console-based **Bank Management System** built with **C++** that manages client records using text files, featuring **CRUD operations**, **file handling**, and a modular design that supports future enhancements.

> **Note:** This repository represents the first stage of the project and will be extended with additional banking features in future updates.

---

## 🚀 Features

- 📋 Display all clients.
- ➕ Add new clients.
- ✏️ Update existing client information.
- 🗑️ Delete clients.
- 🔍 Search for clients by account number.
- 📁 Store client records in text files.
- ✅ Prevent duplicate account numbers.
- 📑 Menu-driven console interface.

## 📥 Installation

Clone the repository:

```bash
git clone https://github.com/MalikAlFuhaidi/Bank-Management-System.git
```

Then:

1. Open the solution (`.sln`) file in **Visual Studio 2022**.
2. Build the project.
3. Run the application.
